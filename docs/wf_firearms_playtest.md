# gunsrpg 枪械战斗试玩说明

## 操作（对标 Guns RPG）

| 操作 | 默认键 | 说明 |
|------|--------|------|
| 开火 | 左键 | 半自动：点射；全自动/可切换枪：按住连射 |
| 瞄准 (ADS) | 右键按住 | 缩小散布、轻微缩小 FOV |
| 换弹 | **R** | 从背包装填弹匣，受「装弹速度」天赋影响 |
| 解除卡弹 | **U** | 卡弹时无法开火，排障受「排障速度」天赋影响 |
| 开火模式 | **B** | 仅 AKM/汤姆逊/Vector/加特林/VSS 等可切换枪 |
| 准星颜色 | **N** | 客户端切换 |
| 准星形状 | **M** | 圆点/十字/圆环/方框 |
| 技能树 | **O** | 与战斗独立 |

## 战斗循环

1. 主手持有枪械，背包内有对应口径弹药。
2. **R** 换弹装满弹匣（新枪弹匣默认为空）。
3. **右键** 瞄准后 **左键** 射击。
4. 随机卡弹时按 **U** 排障。
5. 连发枪可按 **B** 在半自动/全自动间切换。

## 已知限制（相对原版 Guns RPG）

- **第一人称换弹/瞄具动画**尚未接入 `lib.toma.animations`，目前为计时条 + 望远镜式瞄准姿势。
- 附件、电池武器等 M3+ 内容未实现。

## 构建

在 `gunsrpg/` 目录执行 `gradlew build`，将 `build/libs/gunsrpg-*-alpha.jar` 复制到整合包 `mods/`。
